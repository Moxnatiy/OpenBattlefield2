# Оригінальний сервер BF2 у контейнері

Навіщо: мати поруч **еталон**. Наш сервер і клієнт можна звіряти не з
здогадками, а з тим, як поводиться сам рушій.

## Що потрібно

Офіційний інсталятор виділеного сервера від EA — він лежить у грі
користувача (`bf2-linuxded-1.5.3153.0-installer.sh`). Розпакувати без
запуску:

```bash
cd "Game Files/OtherFiles"
env -u DISPLAY sh ./bf2-linuxded-1.5.3153.0-installer.sh --noexec --target linuxded-full
```

`env -u DISPLAY` тут не випадково: інсталятор бачить X11 і намагається
перезапустити сам себе в `xterm`, після чого в терміналі нічого не
відбувається.

## Запуск

```bash
tools/linuxded/run.sh
```

Скрипт збирає образ і піднімає контейнер. Файлів гри в образі немає —
тека сервера монтується ззовні, а налаштування підкладаються з
репозиторію, щоб не чіпати саму гру:

| Файл | Що змінено |
|---|---|
| `serversettings.con` | ім'я сервера, 16 місць, раунд стартує з одного гравця |
| `maplist.con` | лише `dalian_plant gpm_cq 16` — те, що вміє наш клієнт |
| `admin-default.cfg` | пароль віддаленої консолі |

**PunkBuster не вмикається.** У типових налаштуваннях гри `sv.punkBuster 0`,
і теку `pb` в контейнер ми не підкладаємо.

Двійковий файл 2009 року зібраний під x86-64, тож образ теж `linux/amd64`
— на Apple Silicon Docker запускає його через емуляцію. Працює: сервер
завантажує рівень і крутить раунд, займаючи близько 165 МБ і кілька
відсотків процесора.

## Віддалена консоль

```bash
python tools/linuxded/rcon.py "sv.serverName" "sv.maxPlayers" "admin.currentLevel"
```

```
sv.serverName                  -> OpenBF2 reference
sv.maxPlayers                  -> 16
admin.currentLevel             -> 0
gameLogic.getTickets 1         -> Unknown object or method!
```

Останній рядок — це рушій сам каже, що такої команди немає. Рівно те саме
робимо ми, коли команда прийшла, а обробника до неї нема.

Дрібниці протоколу, які довелося з'ясувати:

* вітання й зерно приходять **двома окремими** повідомленнями;
* хеш — `md5(зерно + пароль)` (видно в `admin/default.py`, який лежить у
  сервері відкритим текстом);
* пароль береться **не** з `ServerSettings.con`, а з `admin/default.cfg`;
  без цього файлу пароль порожній і вхід не вдається ніколи.

## Чого ще не можна

**Під'єднати наш клієнт до цього сервера поки не вийде.** Наш мережевий
шар говорить власним протоколом і працює лише через петлю в пам'яті;
побайтова сумісність з оригіналом свідомо відкладена (див. `docs/TODO.md`).
Щоб з'єднатися, треба розібрати мережевий протокол BF2 — і піднятий тут
сервер якраз найкращий стенд для цього.
